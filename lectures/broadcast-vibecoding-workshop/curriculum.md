# 커리큘럼 (안) — 바이브코딩으로 데이터 분석하기

> 방송국 경영/마케팅/광고 담당자 대상 · 오프라인 반나절(3~4시간) · 초안, 시간/순서 조정 가능

## 학습 목표

- 바이브코딩(자연어로 의도를 전달해 결과물을 만드는 방식)의 개념과 한계를 이해한다
- Claude Cowork로 코드를 직접 작성하지 않고도 데이터 탐색·시각화·인사이트 도출이 가능함을 직접 경험한다
- AI 분석 결과를 그대로 믿지 않고 재확인을 요청하는 검증 습관을 익힌다
- 자신의 업무 데이터에 적용할 아이디어를 1개 이상 가지고 돌아간다

## 준비물 (참가자)

- 노트북 1인 1대 (Wi-Fi 연결 가능)
- Claude Cowork 계정/접속 권한
- (선택) 평소 다뤄보고 싶었던 본인 부서 데이터 샘플 (엑셀/CSV)

## 진행 순서 (총 3시간 40분, 휴식 포함)

| 시간 | 분량 | 내용 |
|---|---|---|
| 1부 | 20분 | **오프닝** — 바이브코딩이란 무엇인가, 비개발자도 가능한 이유, 오늘 다룰 내용 미리보기 |
| 2부 | 30분 | **Claude Cowork 둘러보기** — 화면 구성, 자연어로 요청하는 법, 파일 첨부, 결과 확인·되돌리기, 안전장치 |
| 3부 | 40분 | **라이브 데모 ①** — 가상 시청률·광고매출 데이터 불러오기, 탐색, 시간대별 시각화 |
| — | 10분 | 휴식 |
| 4부 | 50분 | **라이브 데모 ②** — 채널 비교, 이상치(특이 날짜) 발견, SNS 버즈-시청률-광고매출 상관분석, 경영진 보고용 요약 리포트 자동 생성 |
| 5부 | 40분 | **직접 해보기** — 같은 데이터 또는 본인 부서 데이터로 직접 질문해보는 실습, 강사 순회 지원 |
| 6부 | 20분 | **정리 & Q&A** — 실무 적용 시 주의점(데이터 보안, 결과 검증), 사내 도입 다음 단계 안내 |

세부 진행 멘트와 실제로 입력할 프롬프트는 [`demo/demo-script.md`](./demo/demo-script.md) 참고.

## 다루지 않는 것 (기대치 조정용)

- 프로그래밍 문법이나 코드 자체를 가르치는 강의가 아님
- 실제 방송국 데이터가 아닌 가상 데이터로 진행 (보안 문제 없음)
- 1회성 워크숍으로 전문 데이터 분석가를 만드는 것이 목표가 아니라, "이런 게 가능하구나"를 체감시키는 것이 목표
